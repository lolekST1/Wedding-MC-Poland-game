# Wodzirej Tycoon

Osobny produkt rozwijany niezależnie od gry reklamowej w root repo
(`index.html` / `index-en.html`), która pozostaje nietykalna.

Docelowo ten katalog to projekt Vite + TypeScript (Phaser 3 dla fazy imprezy,
Preact dla fazy menedżerskiej), budowany w CI i deployowany na GitHub Pages
pod ścieżką `/tycoon/`.

Dokumentacja projektowa:

- `../docs/WODZIREJ-TYCOON-ARCHITEKTURA.md` — stos, architektura, struktura
  projektu, kontrakt integracji faz, plan kamieni milowych M0–M9.
- `../docs/WODZIREJ-TYCOON-BIALE-PLAMY.md` — krytyczna analiza luk, burza
  mózgów i pytania P1–P10 (rozstrzygnięte 2026-07-09: przyjęto propozycje
  domyślne).

Stan: przed M0 (port prototypu). Kod pojawi się tu wraz z kamieniem M0.
